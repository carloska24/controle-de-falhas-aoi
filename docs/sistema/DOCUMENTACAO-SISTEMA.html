Visão Geral do Sistema

🏭
CADService Produtos Eletrônicos — Campinas, SP
Este sistema foi desenvolvido exclusivamente para a CADService Produtos Eletrônicos, empresa fabricante de produtos eletrônicos. A solução digitaliza integralmente o processo de controle de qualidade das linhas de produção SMD (Surface-Mount Technology), substituindo planilhas manuais e registros em papel por uma plataforma web centralizada e em tempo real.

Problema Resolvido

Antes da implantação deste sistema, o processo de controle de qualidade na CADService era realizado de forma manual:

  • Registros de defeitos feitos em papel ou planilhas desconectadas
  • Sem controle preciso do tempo de produção por Ordem de Manufatura (OM)
  • Cálculo manual e demorado de DPMO e índice Sigma
  • Sem rastreabilidade de defeitos por componente, operador ou período
  • Dificuldade em identificar os principais tipos de defeito (análise de Pareto)
  • Processo de reparo e almoxarifado desconectado da produção

Solução Implementada

⏱️
Timer de OM
Controle preciso do tempo de produção por Ordem de Manufatura com pause/resume e persistência em banco de dados.
📝
Registro de Falhas
Lançamento digital de defeitos com designador, Part Number, tipo de defeito, operador e observações.
📊
Dashboard Analítico
Métricas em tempo real: DPMO, Sigma, Pareto de defeitos, tendência temporal e análise por OM.
🔧
Gestão de Reparos
Kanban interativo de falhas aguardando reparo, com rastreabilidade completa de status.
📦
Almoxarifado
Requisições de materiais em fluxo Kanban (pendente → separando → entregue) com notificações.
🔐
Controle de Acesso
RBAC com 5 perfis: admin, operador, reparo, qualidade e almoxarifado. Cada usuário vê apenas o que precisa.

Segurança

🍪
Cookie HttpOnly
O token JWT é armazenado em cookie HttpOnly — inacessível por JavaScript, protege contra XSS.
🔑
JWT — JSON Web Token
Autenticação stateless. O token carrega o perfil do usuário e é verificado a cada requisição.
🔒
Senhas com bcrypt
Hash bcrypt com fator de custo elevado. Senhas nunca são armazenadas em texto puro.
🚦
Rate Limiting
express-rate-limit protege contra brute-force e abuso de API limitando requisições por IP.
✅
Validação com Zod
Todos os endpoints de escrita validam o corpo da requisição com schemas Zod antes de processar.
🌐
CORS Configurado
Apenas origens autorizadas via variável CORS_ORIGIN podem fazer requisições ao backend.

Frontend — Módulos do Sistema

🔐
Login
Tela de autenticação com animação SMD ao fundo (componentes eletrônicos caindo), validação e feedback de erro em tempo real.
⚙️
Operador
Painel principal: timer de OM com shimmer effect (iniciar, pausar, retomar, finalizar), formulário de lançamento de falhas e tabela interativa de registros.
📊
Qualidade
Dashboard com gráficos Chart.js: Pareto de defeitos, tendência temporal e análise por OM. Cálculo automático de DPMO e índice Sigma. Exportação em PDF.
🔧
Reparo
Kanban drag-and-drop de falhas. Cards com designador e PN destacados, acento visual por status (aberto/reparado/cancelado).
📦
Almoxarifado
Kanban de requisições: pendente → separando → entregue. Modal com busca interna, ações em lote, notificação sonora e atalhos Ctrl+S / Esc.
👤
Admin
Gestão completa de usuários: criar, editar, remover e definir perfis. Acesso exclusivo do administrador.
📄
Relatórios
Geração e exportação de relatórios de qualidade em PDF com html2canvas + jsPDF.
🏭
SMT
Módulo de controle da linha SMT (Surface-Mount Technology).

Perfis de Acesso — RBAC

O sistema utiliza Role-Based Access Control (RBAC). Cada usuário possui exatamente um perfil que define quais módulos e ações estão disponíveis. O perfil é verificado no backend a cada requisição — não apenas no frontend.

Glossário

AOI
Automated Optical Inspection — inspeção óptica automatizada de placas eletrônicas na linha de produção.
OM
Ordem de Manufatura — ordem de produção que identifica um lote de placas.
SMD / SMT
Surface-Mount Device / Technology — tecnologia de montagem de componentes eletrônicos na superfície da placa.
DPMO
Defects Per Million Opportunities — defeitos por milhão de oportunidades. Métrica padrão IPC de qualidade.
Sigma (σ)
Índice de qualidade estatístico. Quanto maior, melhor (6σ é praticamente zero defeitos).
Pareto
Análise que identifica os defeitos de maior frequência — regra 80/20 aplicada à qualidade.
RBAC
Role-Based Access Control — controle de acesso baseado em perfis de usuário.
JWT
JSON Web Token — padrão de autenticação sem estado (stateless), assinado digitalmente.
PN
Part Number — código único de identificação de um componente eletrônico.
Designador
Referência do componente na placa (ex: C1 = capacitor 1, R22 = resistor 22, U5 = CI 5).
ORM
Object-Relational Mapping — camada de abstração entre o código e o banco de dados relacional.
CI/CD
Continuous Integration / Continuous Delivery — pipeline automatizado de testes e deploy.
